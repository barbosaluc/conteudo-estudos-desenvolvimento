#cloud/fundamentos 
É um software pronto que você utiliza na internet, sem precisar se preocupar com servidores, sistema operacional, instalação ou infraestrutura.
##### Exemplo 
Pense no Gmail. Você simplesmente acessa e utiliza o e-mail. Não precisa administrar os servidores que fazem o sistema funcionar.
````
SaaS
│
├── Provedor cuida:
│   ├── Servidores
│   ├── Rede
│   ├── Storage
│   ├── Sistema Operacional
│   ├── Runtime
│   ├── Aplicação
│   ├── Atualizações
│   └── Manutenção
│
└── Você:
    └── Utiliza o software
````
#### IaaS x PaaS x SaaS

| Modelo | Ideia principal                                      |
| ------ | ---------------------------------------------------- |
| IaaS   | Você recebe a infraestrutura e configura o ambiente  |
| PaaS   | Você recebe uma plataforma e publica sua aplicação   |
| SaaS   | Você recebe o software pronto e simplesmente utiliza |
